# Agent Market — the front door for BNB Chain's AI agents

Built for **BNB Chain "The Smart Money Era: Build the Era"** (2026-08-05 → 09-09).
The main track: build the discovery-and-hiring marketplace that becomes the official BNB Agent
Studio front door — where users browse, understand, and activate on-chain AI agents by category.

## The bar (from the brief)
- **Functionality** — land → find an agent by category → understand it → activate, minimal friction.
- **Data quality** — real-time, accurate agent data (via the 8004scan ERC-8004 registry), not just counts.
- **Agent diversity** — all four categories surfaced with *equal depth*: Rebalancing, Grid Trading,
  Yield Optimisation, Health Factor Monitoring. Single-category submissions score poorly.
- Agents surfaced must be **live on BSC**; the marketplace must be publicly accessible during judging.

## Our edge / strategy
Most entrants will have no real agents to list. We do the rare thing: build the marketplace **and
seed it with our own genuine, working agents in all four categories** — deployed via BNB Agent
Studio. We have shipped exactly these before: Health-Factor (LIFELINE, Aave liquidation-rescue),
Rebalancing + Yield (RotorVault, FXRP risk-managed vault), Grid/Trading (RotorEdge, BNB Track-2 2nd).
So "all four, equally deep" is a bar we can clear that others can't.
